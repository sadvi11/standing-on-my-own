# Standing on my own

Writing on women and emotional independence.

**[Read it →](https://sadvi11.github.io/standing-on-my-own/)**

Pages are generated from `posts/*.md`. Add a markdown file, push, and a GitHub
Action rebuilds the site — no local setup needed.

See [SETUP.md](SETUP.md) for the four decisions still outstanding: the name and
URL, whether this carries my name publicly, the email list, and the thesis on
the front page.

```bash
cp posts/TEMPLATE.md posts/my-piece.md
python3 build.py        # pip install markdown, once
```
